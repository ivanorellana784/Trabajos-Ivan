Avance Makigami — Checklist de Problemáticas

Tablero para seguir, área por área, qué problemas del proceso ya tienen solución y cuáles siguen pendientes.
🧭 ¿De qué se trata esta página?▾

Este es el seguimiento del trabajo Makigami: un levantamiento de todos los problemas que hoy frenan nuestros procesos, ordenados por área (Reclutamiento, Adquisiciones, etc.).

Cada tarjeta es un problema real, con su descripción y la solución propuesta. A medida que un problema se resuelve, se marca aquí — así el avance queda a la vista sin necesidad de explicarlo.

📖 Cómo leer el tablero▾
  • 1Cada columna es un área. Arriba, el gráfico circular muestra el % de problemas que ya tienen solución.
  • 2En cada tarjeta: Problema (qué pasa) y Solución (qué se hará o se hizo).
  • 3Sí / No indica si el problema ya tiene solución; ⊞ SAP marca los que se resuelven con el nuevo sistema.
  • 4La casilla ✓ del título significa que el problema ya está cerrado y verificado.
